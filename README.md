This is the accompanying paper for "Modal Excitation in Feedback Delay Networks" by Sebastian J. Schlecht, Matteo Scerbo, Enzo De Sena, and Vesa Välimäki, published in IEEE Signal Processing Letters, 2024. The paper can be found [here](https://ieeexplore.ieee.org/document/10689470).
